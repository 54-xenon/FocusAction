# バックグラウンドと通知の設定方法

このアプリでバックグラウンドタイマーと通知機能を有効にするには、Xcodeで以下の設定が必要です。

## 1. Info.plistに権限を追加

プロジェクトの `Info.plist` に以下のキーを追加してください：

### 通知の使用説明
```xml
<key>NSUserNotificationsUsageDescription</key>
<string>タイマー完了時に通知でお知らせします</string>
```

## 2. バックグラウンドモードを有効化

### Xcodeでの設定手順：

1. プロジェクトナビゲーターでプロジェクトファイルを選択
2. ターゲットを選択
3. 「Signing & Capabilities」タブを選択
4. 「+ Capability」をクリック
5. 「Background Modes」を追加
6. 以下のオプションにチェック：
   - ✅ Audio, AirPlay, and Picture in Picture
   - ✅ Background fetch
   - ✅ Remote notifications

## 3. 通知センターのデリゲート設定（オプション）

より詳細な通知制御が必要な場合は、`UNUserNotificationCenterDelegate` を実装できます。

## 実装済みの機能

### ✅ バックグラウンドタイマー
- アプリをバックグラウンドにしてもタイマーは継続
- フォアグラウンドに戻ると自動的に時間を調整

### ✅ 通知
- タイマー完了時に通知
- バックグラウンドから戻った時に残り時間で通知を再スケジュール
- 設定画面でテスト通知を送信可能

### ✅ ダークモード
- システム設定に自動対応
- すべての画面でダークモード対応済み

## 使い方

1. アプリ起動時に通知権限をリクエスト
2. タイマーを開始すると自動的に完了通知がスケジュールされる
3. アプリをバックグラウンドにしてもタイマーは継続
4. 設定画面で通知のテストが可能

## トラブルシューティング

### 通知が届かない場合
1. 設定アプリ → 通知 → FocusAction で通知が許可されているか確認
2. 設定画面の「テスト通知を送信」で動作確認

### バックグラウンドでタイマーが止まる場合
1. Xcodeの「Background Modes」が正しく設定されているか確認
2. デバイスの省電力モードがオフになっているか確認
